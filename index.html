Useful Tags

  • <ul>: Creates an unordered list. Like THIS ONE!
  • <li>: Lists need content, list items are list agnostic, meaning they are used in ordered and unordered lists.
  • <main>: Useful for screen readers to find the main content of your page!
  • <section>: Same concept! Why not break up things into sections instead of just using divs all the time! Oh no div is right under me is'nt he?
  • <div>: Just a container with no inherit attributes, exceedingly useful when formatting pages. Attempt to center a div at your own peril!
  • <h1>-<h6>: Creates headings of differing sizes. NOTE: each page should only have one h1 tag!
  • <p>: Creates a paragraph. Useful if you like to talk alot.
  • <em>: adds some emphasis to what you write
  • <b> or <strong>: b for BOLD, strong for... BOLD!
  • <blockquote>:
    "To quote or not to quote. That is the question!"

SEO Tags

  • <title>: used by search engines like Google to find a website. Modern search engines don't like titles that are too long. Keywords that describe the content is best preferred.
  • <meta name="keywords">: Keywords that describe the content of a site can go in the content attribute of this tag.
  • <meta name="description">: Give a summary of the content of the webpage, displayed to the user and helps them understand what the site is all about.
  • <meta name ="viewport">: A website might be accessed by many different screen sizes, this tag instructs the browser to take into account the device-width when rendering the page.
