Useful Tags

  • ul: Creates an unordered list. Like THIS ONE!
  • li: This is getting meta...I hate meta!
  • main: Useful for screen readers to find the main content of your page!
  • section: Same concept! Why not break up things into sections instead of just using divs all the time! Oh no div is right under me is'nt he?
  • div: Just a container with no inherit attributes, exceedingly useful when formatting pages. Beware: center a div at your own peril!
  • h1-6: Creates headings of differing sizes. NOTE: each page should only have one h1 tag!
  • p: Creates a paragraph. Useful if you like to talk alot.
  • em: adds some emphasis to what you write
  • b or strong: b for BOLD, strong for... BOLD as well.
  • blockquote:
    • "To quote or not to quote. That is the question!"
